# Rising Star Maker / 职场新星梦工厂

## English

*Rising Star Maker* is a replayable internship growth simulator with mouse-based controls and an ASCII visual style, inspired by life-simulation raising games like *Princess Maker* and *Volcano Princess*.

You play as an IT-industry mentor guiding a software engineering intern assigned to you over a six-month period. Each week, you arrange three activities and observe how the intern changes through success, mistakes, opportunities, and pressure. The game does not directly display numeric growth values from activities.

Three choices each week, one honest ending. 

## 中文

《职场新星梦工厂》是一款可重复游玩的实习生成长模拟游戏，使用鼠标操作和 ASCII 视觉风格，灵感来源于养成游戏《美少女梦工厂》《火山的女儿》。

你将以一个 IT 行业 mentor 的视角，陪伴一名分配给你的软件工程师实习生走过 6 个月时间。每周你可以安排 3 个活动，观察他/她在成功、失误、机会与压力中的变化。游戏不会直接显示活动带来的数值成长变化。

每周三个选择，走向一个有迹可循的结局。
